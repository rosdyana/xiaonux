# xiaonux

Real Debian Linux in your browser. Nothing to install.

xiaonux runs a full Debian 13 system (RISC-V, 64-bit) inside a browser tab. The machine runs on the visitor's own computer: an emulated RISC-V processor compiled to WebAssembly. No server runs the VM, and nothing you type leaves the tab unless you turn the network on.

It's made for:

- **Learning Unix.** A real shell for files, pipes, permissions and processes, with step-by-step guides that type commands into the terminal.
- **Python.** Python 3 and pip; numpy, pandas, cryptography, pillow and more install from wheels the page serves, so they work offline.
- **Security learning.** Upload a suspicious file and take it apart with `file`, `strings`, `xxd`, `objdump`, `yara`, `binwalk`, `strace`, `gdb` and `pefile`. Read [SECURITY.md](SECURITY.md) for what is and isn't isolated.

## How it works

```
browser tab
├── page (TypeScript + xterm.js)       web/src/main.ts, web/src/ui/
└── Web Worker                         web/src/vm.worker.ts
    ├── xemu.wasm                      TinyEMU RISC-V emulator + our translator (emu/)
    │   ├── OpenSBI → Linux 6.12 → Debian 13 (image/)
    │   └── translator: hot RISC-V blocks → WebAssembly (emu/wasm/jit.c)
    ├── disk: 4 KB blocks fetched on demand, Brotli-compressed, deduplicated;
    │   your changes are kept in the browser (OPFS)          web/src/disk.ts
    ├── snapshot restore: the page ships a booted machine,
    │   so a warm start reaches the prompt in about 0.4 s
    └── network (off by default)                             web/src/net/
        ├── xiaonux-net helper on this computer (helper/, Rust)
        └── or a small Cloudflare Worker relay (relay/)
```

Measured in Chrome on an M2 MacBook:

| | |
|---|---|
| Warm start to prompt | 0.37–0.46 s |
| Cold start to prompt (100 Mbit) | 1.9 s |
| Downloaded before the first prompt | about 17 MB (28 MB in all, including prefetched disk and translations) |
| Shell loop / Python / gzip benchmarks | 6.8 s / 6.9 s / 6.2 s |

## Quick start (development)

You need macOS or Linux, Node 22+, pnpm, Python 3, and for rebuilding the emulator [Emscripten](https://emscripten.org) in `~/emsdk`. The guest image is built in a Linux VM ([OrbStack](https://orbstack.dev) on macOS, VM name `builder`).

```sh
make wasm             # emulator → dist/vm
make firmware kernel  # OpenSBI + Linux (builder VM)
make rootfs           # Debian 13 riscv64 disk image (builder VM)
make stage-snapshot   # chunk the disk and record the boot snapshot → dist/vm
make serve            # build the page and serve it on http://localhost:5180
make prefetch         # (with serve running) record first-command disk blocks
make jit-bundle       # (with serve running) ship pre-translated hot code
make licenses         # dist/vm/licenses.json for the Licenses page
```

Each target is described in the [Makefile](Makefile).

Repository layout:

| Path | What |
|---|---|
| `emu/` | TinyEMU (vendored, patched), WASM glue, translator, Brotli decoder |
| `image/` | firmware, kernel and Debian image builds; guest agent; staging scripts |
| `web/` | the page (Vite + TypeScript + xterm.js) |
| `helper/` | xiaonux-net, the optional network helper (Rust) |
| `relay/` | the optional network relay (Cloudflare Worker) |
| `bench/` | browser and native benchmarks and UI tests (Playwright) |
| `tools/licenses/` | license manifest generator |

## Network

The machine has no internet by default. Visitors can turn it on two ways:

- **xiaonux-net** (`helper/`): a small program the visitor runs on their computer. It shares that computer's internet with the tab only, on ports 80 and 443, and refuses local-network addresses. The binaries aren't code-signed yet; the page explains how to run them.
- **Relay** (`relay/`): a Cloudflare Worker limited to package hosts (PyPI, Debian, GitHub), with a Turnstile check and per-session limits.
